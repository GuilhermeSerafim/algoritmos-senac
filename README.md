# Algoritmos de Programação II — Senac

Repositório de atividades de Algoritmos de Programação II do Senac. Reúne exercícios Java organizados por aulas e listas; preserva o percurso de estudo, sem representar uma biblioteca ou aplicação única.

## Como navegar

- [Matrizes](src/aula1/matrizes): exercícios da primeira aula.
- [Arquivos](src/aula2/arquivos): diretório de exercícios sobre arquivos.
- [Sistemas de busca](src/aula3/sistemaDeBuscas) e [ordenação](src/aula4): material organizado por assunto.
- [Listas Beecrowd](src/beecrowd): exercícios em listas separadas.
- [Aula final](src/aulafinal): arquivos de exercícios finais.

Como ponto de leitura, [BubbleSort.java](src/aula4/BubbleSort.java) contém um `main`, geração de vetor, ordenação crescente e busca binária, além de métodos de busca linear e ordenação decrescente.

## Execução e limites

O repositório contém fontes Java e configuração de IDE, sem manifesto Maven ou Gradle. Selecione o exercício desejado e confira seu pacote, suas entradas e caminhos de arquivos antes de executá-lo em um ambiente Java. Não há comando único de execução nem versão de JDK fixada para o conjunto.
